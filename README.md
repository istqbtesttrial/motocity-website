# MotoCity Showroom

Site showroom premium pour scooters, construit avec Next.js App Router, Tailwind CSS, GSAP et Resend.

## Stack
- Next.js
- Tailwind CSS
- GSAP
- Resend

## Démarrage

```bash
npm install
npm run dev
```

## Variables d'environnement

Copier `.env.example` vers `.env.local` puis renseigner :

- `RESEND_API_KEY`
- `MOTOCITY_ADMIN_EMAIL`
- `MOTOCITY_FROM_EMAIL`

## Pages
- `/`
- `/products`
- `/products/[slug]`
- `/contact`
